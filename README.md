# AgentInlay

一个本地优先的 Obsidian 知识工作台，把笔记捕获、知识库检查、任务、日历和专注计时集中到同一个可定制仪表盘中。

AgentInlay 当前专注于可靠的本地工作流，并为未来接入 AI Agent 保留扩展空间。现有版本不会连接模型、GitHub、RSS 或其他外部服务。

## 功能

### 快速捕获

- 创建日记、项目日志和收件箱笔记，写入基础 YAML properties，并在创建后直接打开。
- 将灵感追加到按日期归档的 Markdown 文件。
- 所有目标目录均由用户指定，插件不会擅自创建目录。

### 知识库概览

- 统计知识库健康度、收件箱积压和任务完成情况。
- 检查孤立笔记、空笔记、失效链接和缺少 YAML properties 的笔记。
- 展示最近 365 天的笔记创建热力图。
- 知识库检查只读取数据，不会修改或删除笔记。

### 任务与日历

- 管理每日任务和每周任务。
- 支持待办与 DDL、高中低优先级、备注、完成、删除和排序。
- 在月历中查看任务分布和 DDL 紧迫程度，也可以从日期直接创建事项。
- 任务保存在用户指定的 Markdown 文件中，不依赖外部数据库。

### 专注与个性化

- 提供 25 分钟专注和 5 分钟短休息计时器，并记录当天完成的专注轮数。
- 支持 9 种主题、6 档字号、两种布局密度和自定义字体。
- 支持编辑欢迎语、调整卡片顺序与尺寸，以及设置图片裁剪位置。
- 支持在当前会话中切换或上传封面、头像和相框图片。
- 可选择在 Obsidian 启动时或主编辑区为空时自动打开工作台。

## 安装

AgentInlay 要求 Obsidian `1.8.0` 或更高版本。

1. 下载并解压安装包，得到名为 `agent-inlay` 的文件夹。
2. 将该文件夹放入 Vault 的 `.obsidian/plugins/` 目录。
3. 确认目录中包含以下文件：

   ```text
   agent-inlay/
     main.js
     manifest.json
     styles.css
   ```

4. 打开 Obsidian，在“设置 → 第三方插件”中启用 AgentInlay。
5. 点击左侧边栏的仪表盘图标，或通过命令面板运行“AgentInlay: 打开仪表盘”。

## 首次配置

在“设置 → 第三方插件 → AgentInlay”中完成以下配置：

1. 为日记、项目日志、收件箱和灵感库选择 Vault 中已经存在的目录。
2. 根据需要修改任务文件路径。默认路径为 Vault 根目录下的 `AgentInlay 待办.md`。
3. 选择主题、字号、布局密度和卡片布局。
4. 根据使用习惯开启“启动时打开工作台”或“关闭所有页面后打开工作台”。

目录未配置或不存在时，相关捕获操作会给出提示，不会自动写入其他位置。任务文件可以自动创建，但它所在的上级目录必须已经存在。

## 任务文件如何工作

AgentInlay 只管理任务文件中两个标记之间的内容：

```markdown
<!-- agent-inlay:tasks:start -->
<!-- agent-inlay:tasks:end -->
```

标记之外的内容会原样保留。如果只剩一个标记、标记重复或顺序错误，插件会停止写入并提示修复，避免静默覆盖文件。

## 本地优先与隐私

- 不发送网络请求。
- 不包含遥测、云同步或 API 密钥配置。
- 笔记、灵感和任务写入当前 Vault。
- 显示偏好和当天专注轮数保存在 Obsidian 的插件设置中。
- 用户上传的封面、头像、相框图片以及进行中的倒计时只在当前 Obsidian 会话中有效。

## 开发

安装依赖：

```bash
npm install
```

启动监听构建：

```bash
npm run dev
```

执行生产构建和代码检查：

```bash
npm run build
npm run lint
```

生产构建会在项目根目录生成 `main.js`。本地测试时，将 `main.js`、`manifest.json` 和 `styles.css` 放入测试 Vault 的 `.obsidian/plugins/agent-inlay/` 目录，然后重新加载插件。

## 项目结构

```text
src/
  cards/       卡片定义与布局元数据
  data/        预览数据与内置图片
  modals/      捕获、任务和知识库检查弹窗
  services/    Vault、任务和仪表盘动作服务
  views/       仪表盘视图
  main.ts      插件入口
  settings.ts  设置、默认值与配置校验
styles.css     仪表盘与弹窗样式
manifest.json  Obsidian 插件清单
```

参与开发前请阅读 [贡献指南](CONTRIBUTING.md)。版本变化见 [更新日志](CHANGELOG.md)。

## 已知限制

- 封面、头像和相框图片不会跨会话保存。
- 进行中的倒计时不会在关闭工作台或重启 Obsidian 后恢复。
- 热力图依据文件创建时间统计；复制或同步工具可能改变该时间。
- 界面目前以简体中文为主。
- 当前版本尚未提供 Agent Runtime、模型供应商或外部服务集成。
